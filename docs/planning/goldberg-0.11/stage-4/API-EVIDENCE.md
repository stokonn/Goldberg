# Stage4 current primary-document review (WIP)

Reviewed2026-10-18 using official web documentation before adding transport. No live Stage4 API probes were executed, no API payloads/portraits were downloaded for this evidence, and no real cross-provider identity was certified. Stage2 field policy remains default-deny. This record is not a final API compliance sign-off.

- [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API) and [rate limiting](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting): identifying application/version/contact User-Agent, at most1 request/s per source IP absent separate agreement;503 can be overload. Implementation starts at1100ms serialized per app and stops on overload; multiple apps/devices sharing an IP remain an external limitation. No polling jobs. Public reads need no service authentication. Service commercial-use terms remain separate from data licensing; no commercial or paid service provisioning was performed.
- [MusicBrainz database download/license](https://musicbrainz.org/doc/MusicBrainz_Database/Download) and [schema](https://musicbrainz.org/doc/MusicBrainz_Database/Schema): core CC0 versus excluded derived fields. Current projection omits tags/genres/ratings/annotations/editor information/cover art and unknown nested objects. [API examples](https://musicbrainz.org/doc/MusicBrainz_API/Examples) and [work semantics](https://musicbrainz.org/doc/Work) reviewed; full relationship projection not implemented or newly authorized by an allowlist extension yet.
- [Open Opus dedication](https://openopus.org/) and [publisher API usage](https://github.com/openopus-org/openopus_api/blob/master/USAGE.md): CC0 metadata; `/omnisearch/{query}/{offset}.json`. Response rows must be parsed independently of advertised count. API repository GPL code license is distinct from CC0 data. No numeric request SLA found in this review;1200ms serialization is a conservative client policy, not an upstream guarantee. Portrait links do not establish image rights.
- [Wikidata data access](https://www.wikidata.org/wiki/Wikidata:Data_access) and [CC0 licensing](https://www.wikidata.org/wiki/Wikidata:Licensing): Action API entity search/lookup; item data separate from linked article/media rights. Typed cross-ID properties reviewed: [P435 works](https://www.wikidata.org/wiki/Property:P435), [P434 artists](https://www.wikidata.org/wiki/Property:P434), [P436 release groups](https://www.wikidata.org/wiki/Property:P436), [P4404 recordings](https://www.wikidata.org/wiki/Property:P4404). Search titles do not establish identity. Reverse-order, contradictory/deprecated/ranked claim evidence needs further verification.
- [MediaWiki API etiquette](https://www.mediawiki.org/wiki/API:Etiquette), [maxlag](https://www.mediawiki.org/wiki/Manual:Maxlag_parameter): meaningful UA, serial bounded requests, cached reads, JSON-level errors and Retry-After handling. Action requests use maxlag5; HTTP200 maxlag must never become empty success.1200ms client spacing is not a universal Wikimedia limit or quota guarantee.
- [MediaWiki REST reference](https://www.mediawiki.org/wiki/API:REST_API/Reference): `/w/rest.php/v1/page/{title}/with_html` binds content/license/latest revision. No legacy REST summary/TextExtracts dependency added. English/Czech endpoint compatibility and exception licenses have not been live-probed in Stage4; unsupported document licenses remain blocked.
- [Commons reuse](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo): per-file author/license/restrictions/revision, no global image license. Current metadata gate rejects unreviewed public-domain labels and NC/ND/unknown rights; accepts only exact matching known CC-BY/CC-BY-SA identifier and URL. No image-byte transfer/render/redistribution was implemented.

Transport rejects redirects rather than silently forwarding across hosts. Conditional GET/304, documented redirect following and accepted-revision cache policy need follow-up. Timeouts are bounded and JSON/response size is capped2MiB; these are client choices, not provider content guarantees. Oversized article rejection must retain saved content. No paid AI, tracker, backend account or provider credentials were introduced.
