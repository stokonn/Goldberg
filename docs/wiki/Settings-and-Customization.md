# Settings & Customization

Choose Ivory, Nocturne or the system theme; editorial or system typography; accent, density and supported layout preferences. Android font scaling and reduced-motion settings remain relevant. Appearance reset must preserve profile identity, musical favorites, repertoire, drafts, history and badges.

Language supports Czech, English and system selection. User titles, notes, nicknames and original catalogue names are not translated.

Goldberg 0.9.2 places explicit metered-media consent in Data & Storage. It is off by default. Unmetered Wi-Fi permits small portrait downloads automatically. Optional composer biographies/large portraits are requested on their composer page and may be removed there. Cached images work offline. Cache clearing affects downloaded responses/media, not critical journal tables. Downloaded content is separate from practice data.

Backup exports portable journal/profile/settings data. Goldberg 0.9.2 uses format 3/schema 7 and retains import compatibility with format 1/schema 4–5 and format 2/schema 6. Older app versions cannot import a new format-3 backup. Keep your original backups. Restore validates data separately and requires explicit replacement confirmation. Recovery exports differ from portable backups. Session and per-piece CSV exports are separate to avoid double-counting.

Google identity is optional in the 0.9.2 implementation. Credential Manager + Google ID use the real public Web client ID supplied by the owner. The owner reports successful Google authentication on a Samsung Galaxy A55 after an in-place install. This is user-reported manual verification, not physical-device testing by Codex. The owner individually confirmed display-name/avatar import, nickname preservation, authenticated restart, sign-out/local data preservation and account switching on 2026-10-17: PASS — owner-reported manual verification. Codex did not perform these phone tests. Local profiles remain fully usable. Configuration and exact signing requirements are documented in `docs/GOOGLE-IDENTITY-SETUP.md`. No client secret belongs in an APK. A customized nickname or existing avatar is preserved; Google pictures obey metered-media consent. Sign-out retains journal and local profile data. This is not cloud synchronization. See [official Credential Manager guidance](https://developer.android.com/identity/sign-in/credential-manager-siwg).

About retains the seven-tap Bach's Secret activation. 0.9.2 redesigns the existing thirteen-note keyboard and adds a separate logo-long-press terminal easter egg. Neither requires downloaded artwork.
