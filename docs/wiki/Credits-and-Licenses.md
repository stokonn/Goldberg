Catalogue metadata comes from Open Opus, with source links in the application. Composer biographies identify Wikipedia contributors and their source/license. Portraits are selected only when reusable license and artist/source metadata are available; cropping is disclosed. Every image's actual license still applies; a composer's age alone does not establish rights. Do not replace missing licensed portraits with arbitrary web images.

Daily quotations are ten short Robert Schumann excerpts from the 1860 Henry Hugo Pierson translation of Advice to Young Musicians. [Project Gutenberg source and translator credit](https://www.gutenberg.org/ebooks/28219). Czech text is an explicitly labelled Goldberg translation, not a claimed historical Czech edition. Full provenance is maintained in the repository's [quotation source notes](https://github.com/stokonn/Gould/blob/main/docs/QUOTATIONS.md).

The Classic Piano light/dark/monochrome icon comes from the owner-approved Goldberg 0.9.1 assets. The terminal easter egg uses locally authored monospaced ASCII artwork, not an externally downloaded image. Bach's Secret uses the existing synthesized audio engine, not licensed commercial recordings. No Apple interface assets are copied.
