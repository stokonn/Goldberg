# Changelog & Roadmap

- **0.9.1 Beta — The Quality Update:** published. Durable startup, retry/export recovery, bounded note persistence, paged history, localization fixes and supplied Classic Piano adaptive artwork. Automated verification and limitations are in its release notes; no physical-device certification.
- **0.9.0 Beta — The Redesign Update:** published. Editorial themes, four main destinations and CZ/EN groundwork.
- **0.8.0 Beta — Smart Practice:** published. Experimental microphone-based practice detection and durable multi-piece review.
- Earlier releases are listed in the repository changelog and [GitHub Releases](https://github.com/stokonn/Goldberg/releases).

**[0.10 — The Definitive UI/UX Redesign](https://github.com/stokonn/Goldberg/releases/tag/v0.10)** refines Home, Repertoire, Practice, Profile and Settings; adds local composer favorites, Favorite Artist autocomplete and safe post-session piece editing; and introduces additive schema 8 / backup format 4 with support for formats 1–3. It passed 72 JVM tests and 36 executed emulator instrumentation tests. Google identity scenarios passed owner-reported manual testing on a Galaxy A55; Codex did not test on a physical phone. See [Verification](Verification).

**[0.9.2 — Final Redesign](https://github.com/stokonn/Goldberg/releases/tag/v0.9.2)** establishes the unified design, daily Home activity/quotes, compact repertoire/profile/settings, single Practice entry, preserved recovery archives, explicit metered-media controls and keyboard/Tux easter eggs. Optional Google identity passed the six owner-reported manual scenarios; Codex did not perform phone testing. Seventy JVM and 31 executed Android tests pass, with migration/backup/localization/APK verification. See [Verification](Verification) for limitations. The permanent private Project and version milestones track maintenance and future work.

No detailed scope has been approved for 0.10.1 or later versions. Track future ideas in the permanent Development Project; do not infer an encyclopedia expansion, social features or cloud synchronization.
