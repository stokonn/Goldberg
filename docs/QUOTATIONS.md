# Daily quotations: provenance and network policy

Exactly ten short English excerpts are bundled in QuoteLibrary with matching localized string resources. All are attributed to Robert Schumann, *Advice to Young Musicians / Musikalische Haus- und Lebens-Regeln*, the 1860 edition translated into English by Henry Hugo Pierson. Author Schumann died in 1856; translator Pierson died in 1873. The source identifies the scanned edition as public-domain material. No contemporary quotation website or proprietary quote API is used.

Verified source: [Project Gutenberg ebook 28219](https://www.gutenberg.org/ebooks/28219), [English/German text](https://www.gutenberg.org/cache/epub/28219/pg28219-images.html), [plain text](https://www.gutenberg.org/cache/epub/28219/pg28219.txt). The ten excerpt IDs correspond to timekeeping, harmony, tempo, easy pieces, choral singing, opera, old/new art, studying life, perseverance and enthusiasm. The original wording is retained, excluding source emphasis markup. Czech versions are new Goldberg translations of those excerpts, explicitly labelled as such; they are not represented as historical Czech quotations or native-speaker-reviewed translations.

Online mode makes at most one bounded HTTPS source request per local calendar day, recorded before IO and serialized across callers. It verifies that the selected excerpt appears in the source before saving the successful result. It does not invent an API or accept unverified authors/text. Selection is stable by local date; the same day's successful cache is preferred, with the exactly-ten bundled library always available offline. An older day's cache is not shown as today's selection. The source has no availability guarantee; network errors and timeouts use the verified bundled excerpt. The request is approximately 54KB of plain text, not a media collection; no personal data is sent. Media consent rules govern images separately.

Source attribution remains visible on Home. Supplementary licensed composer image metadata remains accessible from portrait credits, independently of quotation attribution. No external image is required for the terminal easter egg or keyboard.
