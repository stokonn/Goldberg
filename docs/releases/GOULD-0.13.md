# Gould 0.13 — Project Renaissance

Gould 0.13 is a pre-release with a lighter, more efficient local practice
experience.

## What's New

- Significantly smaller APK, approximately 6.3 MB.
- Optimized recording metadata loading and database queries.
- More consistent Studio recording-list refresh and recovery behavior.
- Performance and reliability improvements.

## Installation

Download the APK from the GitHub pre-release and install it over the existing
Gould installation. Export a backup before updating. Android 8.0+ is required.

## Notes

- This is a pre-release, not Stable.
- Local practice data remains on the device.
- The application ID, database identity and signing certificate remain
  compatible with Gould 0.12.
- Detailed verification is recorded in
  [the 0.13 release-readiness checklist](../planning/gould-0.13/RELEASE-READINESS.md).
