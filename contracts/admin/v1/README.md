**NOT FROZEN / HTTP UNAPPROVED / INACTIVE.** This is Stage6.12 local audit and
fixture coordination, not formal6.17 or authorization for Stage6.13–6.18.
No real users, credentials, metadata or external fetch. All content is synthetic.

- `fixtures.json`:30 **actual-local-capture** scenes generated by real Node service/
  adapter code over explicit scripted SQL, plus11 **proposal-unapproved** scenes.
  Captures prove observed shapes under those inputs; they are NOT PostgreSQL,
  browser, OAuth, network, transaction-integrity or public HTTP binding proof.
  Dynamic response UUIDs are normalized; no live credentials captured. The test
  audit cursor key is public synthetic material, never a production secret.
- `stage7b-comparison/`: byte-preserved29-case authored corpus and inactive mapping
  proposal from Stage7B. Its `candidate-local` classification means source-reviewed
  authored representative scenes, NOT captured runtime responses. Legacy C6,
  normative design and client conditions stay separate from new actual captures.
- `readiness.json`: G1–G11 comparison with normative/backend/Android/mismatch/
  fixture/resolution/approval/verification fields. G10 stays closed on Android;
  G1–G9 andG11 remain blocked for real integration.
- `stage7b-readonly-source-sha256.json`: actual inspected working bytes, including
  uncommitted Stage7B source. Its committed HEAD alone is not their identity.
- `source-provenance.json`: exact current backend/capture sources and fixture hashes,
  base commit, owner-approved T22 decision and corpus identity; not an API freeze.
